# Charmed Airflow UATs

Automated User Acceptance Tests (UATs) for Charmed Airflow.

## Status

This repo is being scaffolded incrementally. So far it has:

- `pyproject.toml` — project metadata and dependency groups (`lint`, `format`, `integration`)
- `uv.lock` — pinned dependency versions, generated by `uv lock`
- `tox.ini` — task environments wrapping `uv run` commands
- `justfile` — short command aliases wrapping `tox`
- `tests/test_smoke.py` — placeholder test proving the pipeline works end-to-end

Still to come: real UAT test cases, Terraform infra stub.

## Requirements

- [uv](https://docs.astral.sh/uv/) — Python dependency management
- [tox](https://tox.wiki/) — task environments (`uv tool install tox`)
- [just](https://just.systems/) — command runner

## Setup

```bash
uv lock     # resolve and pin dependencies (only needed after editing pyproject.toml)
uv sync     # create .venv and install dependencies
```

## Usage

| Command | What it does |
|---|---|
| `just lint` | Check code style with ruff and codespell |
| `tox -e lint` | Same as above, called directly |
| `tox -e format` | Auto-fix code style with ruff |
| `tox -e integration` | Run UAT tests under `tests/` |
